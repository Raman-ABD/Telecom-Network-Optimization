# Telecom Network Optimization

## Project Overview
This project focuses on telecom network design and routing
optimization using Python and graph algorithms.

## Features
- Telecom network graph creation
- Minimum Spanning Tree using Kruskal's Algorithm
- Shortest path calculation using Dijkstra's Algorithm
- Network visualization
- Interactive web application using Streamlit

## Technologies Used
- Python
- NetworkX
- Matplotlib
- Streamlit

## Project Structure
- data/network_data.csv - Telecom network dataset
- output/optimized_network_map.png - Generated network map
- src/main.py - Main optimization program
- src/web_app.py - Web application
- requirements.txt - Required Python libraries

## Installation

Install Python and the required libraries.

Run this command in the terminal:

pip install -r requirements.txt

## Run the Main Program

python src/main.py

## Run the Web Application

streamlit run src/web_app.py
